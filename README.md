# BancoDeDadosCartografiaDigital
Projeto Banco de Dados Cartografia Digital Religiões Afro-brasileiras IFBA

## Organização do site

- `index.html`: fichário geral e filtros do catálogo.
- `paginas/`: páginas institucionais do projeto.
- `css/site.css`: estilos compartilhados.
- `js/fichario.js`: busca, filtros e apresentação dos registros.
- `fontes.json`: dados das fontes catalogadas.

Abra `index.html` para acessar o fichário e navegar entre as páginas. Use as bandeiras junto ao cabeçalho para alternar entre português, inglês e espanhol; a página atual é mantida ao trocar de idioma. Os textos de interface e institucionais estão traduzidos, enquanto os metadados originais do catálogo permanecem em português.
